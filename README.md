# Central

Manage and organize your files/folders easily using **CENTRAL**!

Below is a guide on how to use this program.

## Usage

1. First, install the zip file. Secondly, extract to a safe location, such being: ``home/username`` directory on linux or if your on windows the usual root directory (like ``C:/``).

    ### Linux & MacOS

    Please run ``./install.sh`` in your bash terminal!

    ### Windows

    Please run ``./install.bat`` in your bash terminal!

---

2. Then once installed, run the script.

    ### Linux & MacOS

    Please run ``./run.sh`` in your bash terminal!

    ### Windows

    Please run ``./run.bat`` in your bash terminal!

    **NOTE**:
    <sub>if you are unable to run the script using ``./run.bat`` in **Windows** or any other *OS*, resort to the following command: ``python central.py``<sub>
